## How Cassie runs this with the AI (Fog Mirror) — the flow

1. **Confirm the plans are in the folder.** Open the job's `01_DESIGN → Plans` folder. The finished plan set should be there as a **PDF** (so the AI can read it). If it's only a `.dwg` (AutoCAD), ask Jesus to **export a PDF of the sheet set into that folder** — the AI can't read a raw DWG.
2. **Ask the AI for the trades:** type to Fog Mirror →
   > "List the trades to bid for **[Castro / Bocian]** from the plans in their folder."
3. **Get the subs per trade:** →
   > "Find 3 top-rated **[trade]** subs near **[Milpitas / San José]** for **[job]**." (Or use this list.)
4. **Verify** each (CSLB + rating + insurance).
5. **Send invitations:** →
   > "Draft a bid invitation to **[sub]** for the **[trade]** scope on **[job]**, due **[date]**." (Same scope to all 3.)
6. **Compare & award:** →
   > "Compare the 3 **[trade]** bids for **[job]**." → Richard picks the winner.
7. **Paperwork:** →
   > "Draft the subcontractor agreement + insurance checklist for **[awarded sub]**." → collect CSLB, COI (RHDP additional insured), W-9, workers' comp, signed agreement → file in `02_CONSTRUCTION → Subcontractors`.
