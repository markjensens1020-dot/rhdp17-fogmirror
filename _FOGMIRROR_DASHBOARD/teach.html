Teach the Bots

Paste or upload a document and pick which bot should learn it. It gets embedded into that bot's memory so it can recall and reason from it. Great for: CA building code, local amendments, RHDP17 SOPs, your process notes.

Tip: for very large documents (whole code books), paste or upload one section at a time (a few pages) so it processes cleanly. You can teach as many sections as you want — they all add to the bot's memory.
